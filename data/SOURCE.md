# Dataset source and attribution

- Dataset: **Iris Species**, Kaggle `uciml/iris`.
- Kaggle page: https://www.kaggle.com/datasets/uciml/iris
- Download endpoint used: https://www.kaggle.com/api/v1/datasets/download/uciml/iris
- Original source: Fisher, R. A. (1936), Iris, UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/53/iris
- Original dataset DOI: https://doi.org/10.24432/C56C76
- Retrieved for this project: 2026-10-28.
- Included file: `Iris.csv`, extracted directly from the Kaggle download archive without editing.
- Rows: 150; columns: Id, SepalLengthCm, SepalWidthCm, PetalLengthCm, PetalWidthCm, Species.
- `Id` is an identifier and is excluded from model inputs. Measurements are in centimetres; Species is the target label.
- SHA-256 of the CSV is recorded in the saved model bundle for traceability.

Please retain attribution when reusing the dataset. See the source pages for licensing and dataset documentation.
